Marcus-facing list. Each outlet gets a private #access=… URL — order UI locks to that outlet. One Master token opens Order + Production + Bill + Backend. Practice secrets — rotate for live · no Drive writes.

How it works

No account login. Token lives in the URL hash (and sessionStorage for same-tab nav). Opening any page without a valid token shows a blocking gate. Outlet tokens cannot open Master tools.

Master

Same token works on every page. Prefer Backend as the Master entry, or Order to test any outlet.
