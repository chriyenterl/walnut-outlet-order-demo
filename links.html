Access links

Marcus-facing list. Each outlet gets a private #access=… URL — the order screen locks to that store. One Master token opens Order, Production, Bill, and Backend. Practice secrets — rotate before any live use. No Drive writes.

How it works

No account login. Token lives in the URL hash (and sessionStorage for same-tab nav). Opening any page without a valid token shows a blocking gate. Outlet tokens cannot open Master tools.

Master

Same token works on every page. Prefer Backend as the Master entry, or Order to test any outlet.

Outlet order links

Send each outlet only their own link. They cannot switch outlets or open Production / Bill / Backend.
